🧬 DESI と TIMS の違い

項目DESITIMS
正式名称Desorption Electrospray IonizationTrapped Ion Mobility Spectrometry
入力ファイル.imzML + .ibd (Bruker/Waters).d フォルダ (Bruker) + Parquet annotation
サンプル選択1サンプル = 1切片 = 1フォルダ1サンプル = 複数アノテーション切片
主な解析手法UMAP + クラスタリングUMAP + DBSCAN + アノテーション
解析時間目安5〜30分（サンプル数次第）10〜60分（イオン数次第）
💡 解析全体の流れ
どちらのモダリティでも、基本的な流れは 「データ準備 → 設定 → 実行 → 結果確認 → インタラクティブ調整」 です。下の図で全体を把握してから、各セクションを読むとスムーズです。
図1: 解析の5ステップ全体フロー

📁 2. データ準備

解析の前提として、生データを サーバー上の固定パス に配置する必要があります。

図2: SFTP直アップロード → サーバー固定パス → アプリ表示 のデータフロー

SFTP接続の詳細手順

WinSCP / Cyberduck のインストールから初回接続までの手順は、 App/docs/SFTP_GUIDE.md を参照してください。 接続情報（ホスト名・ユーザー名・パスワード）はサーバー管理者から取得します。

⚠️ フォルダ命名規則
サンプルフォルダ名は ASCII英数 + アンダースコア を推奨します（例: sample_001, 250621_Ohashi）。 日本語・スペース・特殊文字を含むと、R スクリプトの読み込みで文字化けや失敗の原因になります。

⚙️ 3. 解析設定タブ

サブプロジェクトを開くと、まず「解析設定」タブが開きます。画面は サイドバー（左）+ メインパネル（右） 構成です。

図3: 解析設定タブの画面構成（サイドバー + メインパネル）

主要な入力項目

項目用途「参照...」ボタン
📁 データフォルダ生データの場所✅ ファイルブラウザ起動
📋 アノテーションファイルm/z リスト (xlsx / csv)✅
📤 出力先解析結果の保存先✅
☑ サンプル選択解析対象切片の選択自動列挙
⚙️ パラメータm/z範囲・tolerance等直接入力
💡 「参照...」ボタン + ショートカット
ファイルブラウザモーダル上部に 「DESI生データ / TIMS生データ / 解析出力 / アプリ内部データ」 のショートカットボタンが並んでいます。ワンクリックで対応する /srv/msi/... へジャンプできるので、 パスを毎回入力する必要はありません。

▶ 4. 解析実行 + 進捗確認

設定が終わったら ▶ 解析実行 ボタンをクリック。

1 実行ボタンが ⏹ 実行停止 に切り替わる

2 進捗バー（緑色アニメーション）が表示される

3 黒背景のログコンソールに R スクリプトの出力が流れる

4 セクション処理ごとに「N/M セクション」表示が更新

5 完了すると進捗バーが消え、結果閲覧タブに自動切替

🔍
検索

ログ内文字列を絞り込み表示

⚠️
レベルフィルタ

Error / Warning のみ表示

📜
行数選択

50 / 100 / 200 / 全行

⚠️ 解析中の操作
解析中もブラウザを閉じてOK。サーバー側でバックグラウンド処理が続行されます。 再度アクセスすると、完了済み or 進行中の状態が表示されます。 ただし 「⏹ 実行停止」 は他のメンバーには無効に見えるので、必要なら声掛けを。

📊 5. 結果閲覧タブ

解析完了後、自動的に「結果閲覧」タブに遷移します。表示内容:

🎯
UMAPプロット

2D空間に各ピクセルをマッピング。色はクラスタID。 ホバーでm/z値・座標を確認。

🗺
クラスタ画像

組織切片上にクラスタを色塗り表示。 ピクセル単位の代謝物分布を可視化。

📋
代謝物リスト

アノテーション付きの m/z 一覧。 強度・付加体・分子式・スコアで並び替え可。

📥
ダウンロード

PNG / CSV / RDS をローカルに保存。 SFTPでフォルダごと取得もできる。

🎨 6. インタラクティブ解析

結果を見て「ここのクラスタをマージしたい」「色を変えたい」と思ったら、 インタラクティブタブ で対話的に修正できます。

主な操作

操作やり方用途
🖱 クラスタ選択UMAPプロット上で囲み選択特定クラスタを抽出
🎨 色変更カラーピッカーで色指定論文用に色を統一
🔗 マージ複数クラスタ選択 → マージボタン過分割の修正
✂️ 分割クラスタ選択 → 再UMAP過合併の修正
🚫 除外クラスタ選択 → 除外ボタン背景・ノイズ除去
💾 保存「結果を保存」ボタン新しいRDSとして書き出し
💡 操作はサーバー側で逐次保存
クラスタ操作の途中状態は自動的にサーバー側にキャッシュされます。 ブラウザを閉じて別のPCで再アクセスしても、続きから操作可能です。 ただし最終結果は 「💾 結果を保存」 ボタンで明示的にRDSに書き出す必要があります。

🗂 7. セッション履歴

過去の解析実行履歴を一覧表示します。各エントリには以下の情報:

  • 実行日時 + 実行ユーザー
  • 使用したパラメータ（m/z range, tolerance, adduct 等）
  • 処理時間・出力先パス
  • 「再実行」ボタン: 同じパラメータで再解析
  • 「結果を開く」ボタン: 結果閲覧タブにジャンプ

🛟 8. よくあるエラーと対処法

🛑 Permission denied (/srv/msi/...)

原因: ユーザーが msi-lab グループに属していない

対処: 管理者に sudo usermod -aG msi-lab <username> を依頼 → 再ログイン

🛑 対応ファイルが見つかりません

原因: データフォルダのパスが間違っている／ファイル拡張子が想定外

対処: 「参照...」→ショートカットで正しいパスを選び直す

🛑 R script timeout

原因: 大規模データで R_ANALYSIS_TIMEOUT_SEC 超過

対処: .env の R_ANALYSIS_TIMEOUT_SEC を増やすか、サンプル数を減らす

🛑 vector memory exhausted

原因: Rのメモリ上限超過

対処: .env の R_MAX_VSIZE_GB を増やす or Docker mem_limit を引き上げる

🛑 編集ロック失効 (Lock expired)

原因: 30秒間の無操作でロック自動解放

対処: ページ再読み込み → ロック再取得 → 操作再開

🛑 解析画面が真っ白

原因: ブラウザキャッシュの古い JS が残存

対処: Ctrl+Shift+R で強制再読込

❓ 9. よくある質問 (FAQ)

❓ 解析の途中で停止できる？

はい。実行中に表示される「⏹ 実行停止」ボタンで中断可能。 ただし途中までの出力ファイルは残らないことが多いです。

❓ 別のラボメンバーが解析中だと、自分も使える？

使えます。各ユーザーのセッションは独立しており、別プロジェクトを同時に解析できます。 ただし同じプロジェクトの同じサブプロを編集すると、編集ロックが競合します。

❓ 結果をPNGでまとめてダウンロードしたい

結果閲覧タブの「📥 全画像をダウンロード」または、SFTPで /srv/msi/output/<プロジェクト名>/ をフォルダごと取得。

❓ プロジェクト管理の使い方は？

ランディングページでの操作（新規作成・復元・共有）は 🏠 登録画面ガイド を参照。

操作上の疑問は 🏠 登録画面ガイド も合わせて参照してください。
