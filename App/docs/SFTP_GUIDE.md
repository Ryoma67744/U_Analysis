# SFTPアップロード手順

ラボメンバー向けに、各PCからさくらVPS上の `/srv/msi/` に生データを直接アップロードする手順を解説します。**初回のみ**SFTPクライアント（無料）をインストールすれば、以後はドラッグ&ドロップで完結します。

---

## 1. なぜSFTP？

- 数百MB〜数GBの生データを**アプリ経由でなく直接サーバーに置く**ことで、アップロード時間を最短化
- 通信は完全暗号化（SSH）
- 通信切断時の**レジューム機能**で大容量転送が止まらない
- 各PCから同じサーバーの同じ場所が見えるので、ラボメンバー間で**データ所在が共通化**される

---

## 2. クライアント選択

| OS | 推奨ソフト | DLリンク |
|---|---|---|
| Windows 10/11 | **WinSCP** | https://winscp.net/ |
| macOS | **Cyberduck** | https://cyberduck.io/ |
| Linux | 標準ファイラ (Nautilus等) または `sftp` コマンド | (標準) |

どれも無料・日本語対応。

---

## 3. WinSCP 接続手順（Windows）

### 初回セットアップ

1. https://winscp.net/eng/download.php から「Installation package」をダウンロード
2. インストーラーを実行（推奨設定のままで OK）
3. WinSCP を起動 → 「セッション」→「新しいサイト」を選択
4. 以下を入力:

   | 項目 | 値 |
   |---|---|
   | プロトコル | **SFTP** |
   | ホスト名 | (サーバー管理者から共有された IP / ドメイン) |
   | ポート | `22` |
   | ユーザー名 | (サーバー管理者から共有された個人アカウント) |
   | パスワード | (初回ログイン後すぐに変更すること) |

5. 「保存」→ 名前を付けて保存（次回からダブルクリックで接続）

### 日常の使い方

1. ブックマークから接続 → 認証
2. 左ペイン: 自分のPC / 右ペイン: サーバー
3. 右ペインで `/srv/msi/desi_data/` に移動
4. 左ペインから対象フォルダをドラッグして右ペインにドロップ
5. 転送完了を待つ（途中で切断されても再接続で続きから再開）

---

## 4. Cyberduck 接続手順（macOS）

### 初回セットアップ

1. https://cyberduck.io/download/ から「Cyberduck for Mac」をダウンロード
2. .zip を展開して `Cyberduck.app` を `/Applications/` に移動
3. 起動 → 「新規接続」（Cmd+N）
4. 上部プルダウンで「**SFTP (SSH File Transfer Protocol)**」を選択
5. 以下を入力:

   | 項目 | 値 |
   |---|---|
   | サーバ | (サーバー管理者から共有された IP / ドメイン) |
   | ポート | `22` |
   | ユーザ名 | (個人アカウント) |
   | パスワード | (初回ログイン後すぐに変更すること) |

6. 「接続」→ 認証
7. 接続後、左上のメニュー → 「ブックマーク」→「新規ブックマーク」で保存

### 日常の使い方

1. ブックマークから接続
2. Finder の感覚で `/srv/msi/desi_data/` を開く
3. Finder から対象フォルダをドラッグしてCyberduckにドロップ

## 5. アップロード先対応表

| データ種別 | アップロード先 |
|---|---|
| DESI 生データ (.imzML, .ibd, フォルダ等) | `/srv/msi/desi_data/<サンプル名>/` |
| TIMS 生データ (.d フォルダ等) | `/srv/msi/tims_data/<サンプル名>/` |
| 解析結果のダウンロード | `/srv/msi/output/<プロジェクト名>/` から取得 |

**ルール**:
- フォルダ名はASCII英数 + アンダースコア推奨（日本語可だがトラブル時の対処が複雑になる）
- 同名フォルダがあると上書きされるので、`_v2` `_20260520` 等の接尾辞で衝突回避

---

## 6. アプリ側で表示されるまで

SFTPでアップロード完了したら:

1. ブラウザでアプリを開く
2. 「解析設定」タブ → 「データ管理」サブタブ
3. 「DESI生データ」または「TIMS生データ」のショートカットをクリック
4. 一覧にアップロードしたフォルダが表示されることを確認

表示が遅い場合は **ページを再読込（F5 / Cmd+R）** で更新されます。

---

## 7. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「Permission denied」エラー | サーバー管理者に `msi-lab` グループへの追加を依頼 |
| アップロード途中で切断 | 再接続して同じファイルを再ドロップ → レジューム機能で続きから |
| アプリで表示されない | ページ再読込 / フォルダ名にスペースや特殊文字が無いか確認 |
| 接続できない（タイムアウト） | VPN/ファイアウォール設定、サーバー稼働状態を管理者に確認 |
| パスワードを忘れた | サーバー管理者にリセット依頼 |

---

## 8. セキュリティ注意事項

- パスワードは**他人と共有しない**（個人アカウント単位）
- 公開鍵認証への移行を推奨（管理者にお問い合わせください）
- 不要になったアカウントは管理者に削除依頼
