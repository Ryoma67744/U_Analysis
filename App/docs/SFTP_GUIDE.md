# SFTPアップロード手順

ラボメンバー向けに、各PCからさくらVPS上の `/srv/msi/` に生データを直接アップロードする手順を解説します。**初回のみ**SFTPクライアント（無料）をインストールすれば、以後はドラッグ&ドロップで完結します。

---

## 1. なぜSFTP？

- 数百MB〜数GBの生データを**アプリ経由でなく直接サーバーに置く**ことで、アップロード時間を最短化
- 通信は完全暗号化（SSH）
- 通信切断時の**レジューム機能**で大容量転送が止まらない
- 各PCから同じサーバーの同じ場所が見えるので、ラボメンバー間で**データ所在が共通化**される

---

## 2. クライアント選択

| OS | 推奨ソフト | DLリンク |
|---|---|---|

## 3. WinSCP 接続手順（Windows）

新規PCでは **初回のみ** インストールと接続設定を行います。一度設定すれば、次回からは保存したサイトをダブルクリックするだけで接続できます。

### 3-1. インストール（新規PCで初回のみ）

1. https://winscp.net/eng/download.php を開き、「Installation package」をダウンロード（無料・日本語対応）
2. ダウンロードした `WinSCP-x.xx-Setup.exe` を実行
3. インストーラーの指示に従って進める（「標準的なインストール」のままで OK）
   - インターフェースは **「コマンダー」** を推奨します。左=自分のPC／右=サーバーの2画面表示になり、操作が分かりやすくなります
4. インストール完了後、WinSCP を起動

### 3-2. 接続設定（新規PCで初回のみ）

1. WinSCP を起動すると「ログイン」ダイアログが開きます → 左上の **「新しいサイト」** を選択
2. 以下を入力:

   | 項目 | 値 |
   |---|---|
   | プロトコル | **SFTP** |
   | ホスト名 | `133.167.73.188`（管理者からドメインを案内された場合はそちら） |
   | ポート番号 | `22` |
   | ユーザー名 | (管理者から共有された個人アカウント) |
   | パスワード | (管理者から共有された初期パスワード) |

3. **「保存」** → サイト名（例: `MSIサーバー`）を付けて保存
   - 共用PCでは **「パスワードを保存」のチェックを外す**（セキュリティのため、毎回入力を推奨）
4. 保存したサイトを選び **「ログイン」**
5. 初回接続時のみ **「ホスト鍵を信頼しますか？（未知のサーバーに接続しようとしています）」** という警告が表示されます
   - 管理者から共有されたフィンガープリント（鍵の指紋）と一致することを確認し、**「はい」** を選択（鍵がキャッシュされ、次回以降は表示されません）
6. パスワードを求められたら入力してログイン
   - ログインできたら、**初期パスワードは早めに変更**してください（変更方法は管理者の案内に従ってください）

### 3-3. 日常の使い方（2回目以降）

1. WinSCP を起動 → 保存したサイト「MSIサーバー」を **ダブルクリック** で接続
2. 画面は左右2ペイン構成です（**左=自分のPC／右=サーバー**）
3. 右ペイン（サーバー側）で `/srv/msi/desi_data/`（TIMSデータは `/srv/msi/tims_data/`）へ移動
   - 上部のパス欄に直接入力するか、`Ctrl+O`（ディレクトリを開く）で移動できます
4. （必要なら）右ペインの空白を右クリック →「新規」→「ディレクトリ」でサンプル用フォルダを作成
   - フォルダ名は ASCII 英数＋アンダースコア推奨
5. 左ペイン（自分のPC）からアップロードしたいフォルダ／ファイルを選び、右ペインへ **ドラッグ＆ドロップ**（または `F5` キー）→ 確認ダイアログで「OK」
6. 転送完了を待ちます（途中で切断されても、再接続して同じものを再ドロップすればレジュームで続きから再開されます）
7. アップロード先と命名規則は「**5. アップロード先対応表**」、アプリに表示させる手順は「**6. アプリ側で表示されるまで**」を参照
8. 解析結果を取得する場合は、右ペインで `/srv/msi/output/<プロジェクト名>/` を開き、左ペイン（自分のPC）へドラッグしてダウンロード

## 4. Cyberduck 接続手順（macOS）

### 初回セットアップ

1. https://cyberduck.io/download/ から「Cyberduck for Mac」をダウンロード
2. .zip を展開して `Cyberduck.app` を `/Applications/` に移動
3. 起動 → 「新規接続」（Cmd+N）
4. 上部プルダウンで「**SFTP (SSH File Transfer Protocol)**」を選択
5. 以下を入力:

   | 項目 | 値 |
   |---|---|
   | サーバ | `133.167.73.188`（管理者からドメインを案内された場合はそちら） |
   | ポート | `22` |
   | ユーザ名 | (個人アカウント) |
   | パスワード | (初回ログイン後すぐに変更すること) |

6. 「接続」→ 認証
7. 接続後、左上のメニュー → 「ブックマーク」→「新規ブックマーク」で保存

### 日常の使い方

1. ブックマークから接続
2. Finder の感覚で `/srv/msi/desi_data/` を開く
3. Finder から対象フォルダをドラッグしてCyberduckにドロップ

## 5. アップロード先対応表

| データ種別 | アップロード先 |
|---|---|
| DESI 解析用テーブル（`.txt`） | `/srv/msi/desi_data/<サンプル名>/` |
| TIMS 解析用 Parquet、SCiLS 変換用 CSV | `/srv/msi/tims_data/<サンプル名>/` |
| imzML 登録用の `.imzML` + `.ibd` ペア | `/srv/msi/tims_data/<サンプル名>/`（登録後は TIMS 互換 Parquet として使用） |
| 解析結果のダウンロード | `/srv/msi/output/<プロジェクト名>/` から取得 |

`.d` フォルダを置くだけでは解析入力になりません。SCiLS 等で対応するテーブルまたは
imzML / ibd ペアを書き出してから、必要な変換・登録を行ってください。

**ルール**:

- フォルダ名はASCII英数 + アンダースコア推奨（日本語可だがトラブル時の対処が複雑になる）
- 同名フォルダがあると上書きされるので、`_v2` `_20260520` 等の接尾辞で衝突回避
- imzML は同じ名前の `.imzML` と `.ibd` を同じフォルダへ転送し、両方の完了を確認してから登録
- imzML 登録後のファイルを移す場合は、`sample.parquet` と `sample.imzml.json` を一緒に保管

### SFTP とアプリのパスの違い

下表はホスト側を `/srv/msi/` とした標準マウント構成の例です。サーバーの設定が異なる場合は
「データ管理」の配置表示または管理者に確認してください。

| SFTP で見える場所 | アプリに入力する場所（コンテナ内） |
|---|---|
| `/srv/msi/desi_data/` | `/app/Data/DESI/Data/` |
| `/srv/msi/tims_data/` | `/app/Data/TIMS/Data/` |
| `/srv/msi/output/` | `/app/Data/Other/output/` |

例えば、SFTP で `/srv/msi/tims_data/sample/sample.imzML` に置いた場合、imzML 登録画面には
`/app/Data/TIMS/Data/sample/sample.imzML` と入力します。ブラウザを開いている PC のパスではありません。

## 6. アプリ側で表示されるまで

SFTPでアップロード完了したら:

1. ブラウザでアプリを開く
2. 「解析設定」タブ → 「データ管理」サブタブ
3. 「DESI生データ」または「TIMS生データ」のショートカットをクリック
4. 一覧にアップロードしたフォルダが表示されることを確認

表示が遅い場合は「🔄 再読込」を押します。必要に応じてページも再読込（F5 / Cmd+R）してください。

### 解析に使用するまで

- `.txt` / 登録済み `.parquet`: 解析設定の「データフォルダ・サンプル選択」で、
  対応する装置・データフォルダ・対象ファイル／切片を選びます。
- SCiLS の CSV 群: サイドバー「🔄 SCiLS 変換」で Parquet に変換してから TIMS 解析を設定します。
- `.imzML` + `.ibd`: サイドバー「🧬 imzML 入出力」で **「imzML + ibd → Parquet 登録」**を選び、
  入力 `.imzML` と出力 `.parquet` の絶対パスを指定します。登録完了後に、その Parquet のあるフォルダを
  TIMS のデータフォルダに指定します。対象は共通 m/z 軸・単一 z 面のデータです。

アップロードや imzML 登録だけでは、UMAP・クラスタ解析は始まりません。
imzML の操作・対応範囲は [IMZML_IO.md](IMZML_IO.md) を参照してください。

### imzML 出力 ZIP を取得する

「🧬 imzML 入出力」で **「登録済み Parquet → imzML + ibd ZIP」**を選びます。
入力には登録済み Parquet（同名の `.imzml.json` が必要）、出力には例えば
`/app/Data/Other/output/sample_export.zip` を指定します。
完了後、SFTP では `/srv/msi/output/sample_export.zip` から取得できます。
現時点では imzML 入出力画面にブラウザのダウンロードボタンはありません。

## 7. トラブルシューティング

| 症状 | 対処 |
|---|---|
| アプリに出ている `/app/...` が WinSCP に無い | `/app` はコンテナ内のパスで、ホストには存在しない。対応するホスト側の場所は `App/docs/DATA_LAYOUT.md` の「2. コンテナとホストのマウント対応」を参照。結果が `/app` 直下にある場合はアプリの「解析設定」→「データ管理」→「📦 フォルダの移動」で `/srv/msi/output` 側へ移せる |
| 「Permission denied」エラー | サーバー管理者に `msi-lab` グループへの追加を依頼 |
| アップロード途中で切断 | 再接続して同じファイルを再ドロップ → レジューム機能で続きから |
| アプリで表示されない | ページ再読込 / フォルダ名にスペースや特殊文字が無いか確認 |
| imzML はあるのに解析対象に出ない | まず「🧬 imzML 入出力」で Parquet 登録し、TIMS のデータフォルダに登録先を指定 |
| imzML 登録で ibd が見つからない | 両方の転送完了、同じフォルダ、拡張子を除いた名前の一致を確認 |
| imzML 出力で manifest がないと言われる | 入力が imzML 登録済み Parquet か確認。同名 `.imzml.json` を同じフォルダに置く |
| 接続できない（タイムアウト） | VPN/ファイアウォール設定、サーバー稼働状態を管理者に確認 |
| パスワードを忘れた | サーバー管理者にリセット依頼 |
