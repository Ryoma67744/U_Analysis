# クラスタ番号の自動配置

UMAP・Spatial Mappingの番号は、各クラスタの最大の連続領域から内側の観測点を選ぶ。
全点の平均座標では、複数の島の間やリングの穴に番号が置かれるため、この方法へ変更した。
点の座標、クラスタ割当、R解析、定量値は変更しない。番号表示がOFFなら領域計算を省略する。

## 利用方法と保存位置

- 保存位置がない番号は自動配置される。新しい自動位置を描画だけで固定保存しない。
- 保存済み位置は従来どおり優先する。
- 通常・全画面の「番号を自動配置に戻す」は、現在表示している番号の固定位置だけ解除する。
  他サンプル・他表示の固定位置は残す。番号表示がOFFのときは、番号を表示する案内を出す。
- 解除後のドラッグは、その番号の新しい固定位置として保存する。
- originalとmerged、統合UMAPとサンプル別UMAPの保存位置は分離する。
  mergedを既に描画している経路で適用し、サンプル別・全画面の描画点や表示モードの仕様は変更しない。
- H&E重ね合わせは同じ観測セルの射影先へ自動配置する。H&Eの座標をMSI位置として保存しない。
- 既存の固定位置を回転・反転へ自動追従させる座標系移行は行わない。
  追従が必要な場合は「番号を自動配置に戻す」で固定を解除する。

## 面積と配置点の定義

### Spatial

除外前・丸め前の観測座標から格子間隔を求め、上下左右の4近傍で領域を分ける。
面積は重複を除いた占有セル数とX/Yの格子間隔の積。クラスタ除外後に残ったセルが計算対象になる。
最大領域の内部で、背景セルまでの距離が最大になる観測セルを選ぶ。
X/Yの間隔が異なる場合も距離計算へ反映する。

配置関数は元の行インデックスを返す。図の全点に適用済みの回転・反転・丸め結果から
該当セルの座標を取り出すため、番号だけ回転中心が変わることはない。
格子と判定できない場合は不規則点群用の推定へ移る。

### UMAP

UMAPには画素領域がないため、共通グリッド上で占有面積を推定する。
ズーム、画面幅、マーカー径、文字サイズとは独立したデータ座標の面積であり、
その時点の画面でマーカーが塗るピクセル数とは区別する。

長辺512のグリッドを使い、全点共通の距離制限内で最近傍のクラスタへ領域を割り当てる。
支持半径は正の最近傍距離の90百分位を使い、中央値の3倍で制限してから1.25倍する。
この値は合成の複数島・密度差・外れ値テストで検証した初期設定であり、実データ全般の精度保証値ではない。
共通の距離制限により、孤立点を無制限に広い領域へ膨らませない。
クラスタを除外しても、残る番号の領域尺度・所有関係は除外前の点群を基準にする。

最大面積の4近傍領域を選び、その内部の観測点で背景からの距離が最大の位置を使う。
同面積・同距離は領域重心との距離、座標順で解決する。入力行順やクラスタの色に依存させない。
極端な密度差や非常に小さいクラスタでは、領域の推定自体に限界がある。

## 退化ケースと資源制限

有限点がないクラスタは番号を生成しない。領域を推定できない、座標が競合する、
処理上限を超える場合は中央値に近い実在点へ戻し、`LabelAnchor.reason`で理由を区別する。
この代替位置には最大面積の保証はない。単純な平均座標へ黙って戻す処理は行わない。

領域抽出はクラスタごと、距離計算は選んだ領域に対して行い、全点間距離行列を作らない。
文字の中心の配置が対象であり、細い領域へ文字全体が必ず収まることや、全ラベルの重なりゼロは保証しない。

結果キャッシュは入力内容・行順・参照格子・計算設定をキーとする。
32件、参照を含む合計200万点、合計1万アンカーで制限し、入力座標配列を保持しない。
返却する辞書は独立させ、凍結したアンカーを使って利用側の変更が他の図へ漏れないようにする。
色・ズーム・文字サイズが変わっても同じ入力なら再利用できる。

開発時の合成20万点・30クラスタ（Python 3.12 / NumPy 2.3.5 / SciPy 1.18.1）では、
Spatial初回0.190秒、再利用0.044〜0.060秒、UMAP初回0.930秒、再利用0.043〜0.059秒だった。
ハードウェア・配置・断片化の程度で変わる測定例であり、実データの応答時間の保証ではない。

## 位置の解除と古い操作への対策

JSONとブラウザStoreの両方から対象位置を解除する。
JSON更新はファイルロック内で最新内容を読んで行い、原子的に置き換える。
旧共通JSONを使用していた場合は手法別ファイルへ内容を引き継ぎ、対象だけ解除する。
手法別ファイルを空でも残すことで、旧共通JSONから固定位置が復活することを防ぐ。

図のメタデータにデータパス、読込識別子、手法、表示種別、サンプル、更新番号、
注釈と実クラスタIDの対応を持たせる。再配置前のドラッグや別データの通知を保存しない。
ドラッグ保存では今回移動した番号だけを更新し、古いStore全体を再保存しない。
来歴が確認できない画面スナップショットも保存元として使用しない。

## 検証

`test_cluster_label_placement.py`は島の面積、リング、密度差、外れ値、異方格子、行順、退化条件を検証する。
`test_cluster_label_placement_cache.py`はデータ切替・変更・行順・設定差、容量制限、並列呼び出しを検証する。
`test_cluster_label_rendering.py`は描画・回転・反転・H&E射影・保存位置優先・出力の対応を検証する。
`test_label_position_reset.py`は対象限定の解除、旧形式、古いイベント拒否、表示間の分離を検証する。
`e2e/test_cluster_label_placement_browser.py`は実PlotlyとDashで再配置、ドラッグ通知、再読込を通す。

実データに対する見た目の最終確認では、元図と新図を同じ表示条件で比較する。
合成データのテスト成功を、個別の実データでの配置確認と同一視しない。
