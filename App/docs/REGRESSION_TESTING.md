# 「結果が変わっていない」ことの確認手順（回帰チェック）

## これは何のための作業か
新版（DESI は **v15**、TIMS は **ver5**）では、これまでプログラムの奥に固定で
埋め込まれていた設定値を「表に出して名前を付ける」整理を行いました。
この整理は **計算結果を変えないこと（＝挙動不変）** を狙ったものです。

本当に結果が変わっていないかを、**旧版（v14 / ver4）と新版（v15 / ver5）を
同じデータ・同じ条件で走らせ、出力を突き合わせて**確かめます。
これが OK であることが、以降のすべての作業の土台になります。

> なぜあなたの環境で行うのか：この照合には実際の測定データと R（Seurat 等）の
> 解析環境が必要で、開発側の環境では実行できないためです。

---

## 用意するもの
- 代表的なデータセット 1 つ（小〜中規模で構いません。3 経路＝補正なし／Harmony／
  RPCA が動く構成だと理想的）。
- R（Seurat、jsonlite。`aricode` があれば参考指標も出ます）。

---

## 手順

### 手順0（任意・事前確認）：明示した設定値が「以前の初期値」と同じか目視確認
新版では `n.neighbors=30 / min.dist=0.3 / metric="cosine"` などを **はっきり明示**
しました。これらが Seurat の既定値と本当に同じかを次のコマンドで一覧表示できます。

```
Rscript App/Script/helpers/regression_check.R --print-seurat-defaults
```

表示された既定値が、新版スクリプトの設定値（`UMAP_*` / `CLUSTER_*`）と一致して
いれば、「明示しただけで中身は同じ」という想定どおりです。

### 手順1：新版で 1 回流す（出力Bを作る）
いつもどおりアプリで解析を実行します（現在の標準は v15 / ver5）。
できた出力 RDS を **B（新版）** とします。出力先フォルダのパスを控えてください。

### 手順2：旧版に一時的に切り替えて、同じデータでもう 1 回流す（出力Aを作る）
1. `App/app/config.py` のテンプレ参照を、一時的に旧版へ変更します。
   - DESI: `DESI_V8_TEMPLATE_PATH` を `260422_DESI-UMAP_Template_v14.R` に
   - TIMS: `TIMS_V8_TEMPLATE_PATH` を `260525_DBSCAN_With_cluster_ver4_no-png_slim.R` に
2. **手順1とまったく同じデータ・同じ設定** で解析を実行します。
   できた出力 RDS を **A（旧版）** とします。
3. 確認が終わったら、`config.py` を **元（v15 / ver5）に戻して**ください。

> ポイント：UMAP やクラスタ分けは乱数を使いますが、Seurat は既定で乱数の種を
> 固定するため、同じデータ・同じコードなら結果は毎回同じになります。本チェックは
> その「同じになるはず」を確かめるものです。

### 手順3：2 つの出力を突き合わせる
```
Rscript App/Script/helpers/regression_check.R \
    --rds-a <Aのパス: 旧版の出力.rds> \
    --rds-b <Bのパス: 新版の出力.rds> \
    --out   regression_result.json
```

## 結果の読み方
- **[1] クラスタの分かれ方** … 「不一致スポット数 0 / 総数」で **PASS**。
  もし不一致が出た場合、参考の「調整ランド指数(ARI)」が 1.0 なら
  “番号の振り直しだけ”の可能性、1.0 未満なら分かれ方そのものが変わっています。
- **[2] UMAP 地図座標** … 「最大絶対差」が許容（既定 1e-6）以内なら **PASS**。
- **[3] 参考：途中座標（PCA / Harmony / RPCA）** … 念のための補助情報です。
- 最後の **総合判定** が **PASS（挙動不変とみなせる）** であれば成功です。

`PASS` であれば、設定値の整理によって結果は変わっていない、と確認できます。
`FAIL` の場合は、どの項目で差が出たかを上の表示で確認し、共有してください
（その差分が次の修正対象になります）。

## 補足
- 比較はスポット（細胞）の名前で突き合わせるため、行の並び順が違っても問題ありません。
- DESI と TIMS は別々に確認してください（テンプレが別のため）。
- 既定のクラスタ列名は `seurat_clusters` です。別名の場合は `--cluster-col <列名>` を付けます。
