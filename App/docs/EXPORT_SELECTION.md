# 解析済みデータを選んで数値出力する（ver75.1）

「データ出力 (UMAP cluster)」で、解析した群・個体・切片の一部だけを出力できます。たとえばCtrl・KO1・KO2を一緒に解析した結果から、CtrlとKO2だけを取り出せます。再解析は行いません。

## 操作手順

1. インタラクティブ画面で解析結果を読み込み、「データ出力 (UMAP cluster)」を開きます。
2. 出力手法（PCA・Harmony・RPCA）を選び、「出力対象」を「選択した解析済みデータ」にします。
3. 最初は全切片が選択されています。CtrlとKO2だけにする場合は「全解除」を押し、「群から一括選択」でCtrlとKO2を選んで「選んだ群を追加」を押します。KO1だけを「選んだ群を除外」で外す方法もあります。
4. 必要なら個体／独立試料IDで一括追加・除外し、切片のチェックで調整します。群と個体の操作は、同じ切片チェック一覧を書き換えます。
5. 対象の群名・独立試料数・切片数・解析済み画素数を確認して、出力を開始します。

選択対象と、UMAP図に表示する群の設定は独立しています。図でKO1だけを表示していても、出力対象にCtrlとKO2を選べます。

対象をすべて外すと出力を停止し、選択を促します。「全体（従来の出力範囲）」へ切り替えると従来の出力と未解析切片の除外設定を使用します。結果フォルダを変更した場合は、出力対象を選び直してください。

## 出力対象と数値の意味

| 項目 | 選択出力の動作 |
|---|---|
| 対象画素 | 選択した切片のうち、選択した出力手法の解析結果に存在する画素だけ |
| 複数手法 | 画素集合の和集合。ある手法にない画素は、その手法のクラスタ欄が空欄 |
| 強度 | 入力Parquet／TXTの保存値を保持。入力がRMS等で正規化済みならその値 |
| UMAP座標 | 現在の表示手法が出力手法に含まれる場合はその手法、それ以外は選択順の先頭の手法。座標がない画素は空欄。他手法の座標で埋めない |
| 集計 | 対象画素を抽出してから平均・SD・nを計算。nは画素数であり、独立試料数ではない |
| 列の選択 | 識別子や群の列を出力しなくても、抽出には内部の対応キーを使用 |
| m/z一覧 | 選択画素を含む入力ファイルのfeature列一覧。選択画素で非ゼロのピークだけを抽出する機能ではない |

複数手法をまたぐ同一画素の群・切片などが矛盾する場合は、混在を避けて停止します。手法別の対象画素数とUMAP座標の採用手法は完了表示と出力条件に記録します。

## 対応形式と記録

- TIMS（登録済みimzML由来のParquetを含む）: CSV・Parquet・Excel。m/z一覧のみの出力にも対応します。
- DESI: Excel。元のTXTヘッダーと測定値を保持します。
- 選択出力のファイル名には `_selected` を付けます。出力条件には対象の群・個体・切片ID、解析済み画素数、手法別画素数、選択の署名を記録します。画素データを出力した場合は実際の出力対象画素数も記録します。
- 出力開始時の対象・メタデータを固定します。生成中に画面の選択や群情報を変えても、そのジョブの対象は変わりません。

新しい結果では元ファイルID＋元画素IDで照合します。元IDを持たない旧結果は、Sample名と空間座標（小数4桁）の一致で照合します。曖昧な名前の部分一致や別ファイルへの推測は行わず、対応が不明・重複・欠損の場合は説明付きで停止します。

この機能は「データ出力 (UMAP cluster)」を対象とします。解剖×クラスタの解析用ZIP出力と、独立したParquet→imzML出力の対象設定は、それぞれ従来どおりです。

## 検証

`test_export_selection*.py`で対象の照合・画面状態・ジョブ固定・実ファイル出力を検証します。`tests/e2e/test_export_selection.py`では合成データを用い、実ブラウザの群選択からCSVダウンロードまで操作し、CtrlとKO2の強度・UMAP・クラスタ・元画素IDを比較します。RDS抽出部分は固定データで置換しているため、本番規模のR/Seurat解析や大容量出力の性能試験を代替するものではありません。
