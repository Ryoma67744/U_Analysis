# 切片を選んで解析する（ver67.1）

通常は解析対象の切片／ROIを選び、必要な場合だけ群情報や追加DB照合を設定します。画面のヘルプは `/help/analysis` から開けます。

## 最初の解析

1. DESI／TIMS、データフォルダ、解析するファイルを選びます。TIMSでは追加フォルダからも選択できます。
2. 「解析対象の切片／ROI」で対象を選びます。別ファイルの同名ROIは独立して選択できます。
3. ROIの意味が未登録なら、「切片」または「切片内領域」を一度指定します。
4. 正規化・変換・m/zアライメントの設定と、開始前の対象数・算出結果の表示を確認します。
5. 解析を開始します。

全解除は「解析対象なし」です。全画素へ戻す操作にはなりません。

| 有効な統合単位 | 計算する結果 |
|---|---|
| 1切片 | PCA。Harmony・RPCAは統合単位不足として未実行を記録 |
| 2切片以上 | PCAを保存後、同じ切片単位でHarmony・RPCAを個別に実行 |

PCAは未補正の比較基準です。補正前の結果を見る場合は、閲覧画面でPCAを選びます。Harmony・RPCAでは生物学的な差も変わり得るため、PCAと併せて評価してください。

## ROIの意味

| データの構成 | 指定する意味 | 統合単位 |
|---|---|---|
| 1ファイルのROI1〜ROI6がそれぞれ別切片 | 切片 | 選んだ各切片 |
| 1切片内のROIが脳・肝臓などの領域 | 切片内領域 | 親切片 |
| ROIのない1ファイル | 切片全体として扱う | その切片 |

選択したROIは画素の絞り込みに使います。切片内領域を選ぶだけで、臓器ごとに独立したバッチ補正が始まることはありません。

## 群・独立試料を登録する

「群情報を設定（任意）」を開き、選択済み切片へ個体／独立試料IDと群を登録します。未入力でも解析できます。群・個体情報は色分け、表示の絞り込み、切片数・独立試料数の確認、出力に使います。

**解析対象と他の設定が同じなら、群名や個体IDの入力・変更だけで数値解析の結果は変わりません。** Harmony・RPCAの補正単位は切片のままで、ctrl／KOの2群を補正単位にする設定ではありません。この登録だけで、個体を単位とするctrl対KOの群間検定は行いません。

「個体／独立試料ID」「群」のセルを直接編集できます。表の左端のチェックは、群名を一括設定する行の指定です。解析対象の切片選択には影響しません。行を選び、下の欄に群名を入力して「選択行に群を設定」を押します。

6匹の別々の個体から各1切片を採取した場合の入力例です。画面内の例は説明用で、解析データには自動登録しません。

| 切片の例 | 個体／独立試料ID | 群 |
|---|---|---|
| 01 | C1 | ctrl |
| 02 | C2 | ctrl |
| 03 | C3 | ctrl |
| 04 | K1 | KO |
| 05 | K2 | KO |
| 06 | K3 | KO |

同じ個体の連続切片には同じIDを指定します。例えばC1の切片が3枚あっても、独立試料数は1例です。個体IDを空欄にした切片は、独立試料数として自動的に1例ずつ数えません。

閲覧画面の「群・個体情報」では、次の操作ができます。

- 群ごとの切片数と独立試料数を確認する。個体ID未設定の切片数は別に表示する。
- UMAPの「色分け」を「群」に切り替える。
- UMAP・空間表示の対象群を絞り込む。
- 群名・個体IDだけを編集して保存する。測定強度、PCA、クラスタ、H&Eの対応は変更しない。
- 「画素・切片メタデータCSV」で、表示対象の画素ID・切片・群・個体と座標・クラスタを出力する。

画素、ROI、連続切片の数を独立した生物学的Nとして数えません。今回の群登録機能は、既存のクラスタマーカー検定を「N=3対3の群間検定」に変更するものではありません。

群編集は結果フォルダの `section_manifest.json` に保存します。解析時の条件記録は変更せず、閲覧・出力時に現在の群情報を重ねます。同じ結果を開く手法・共有画面でも、保存した群情報を使用します。

## 分子名と追加DB照合

| 状態 | 表示名 |
|---|---|
| 有効なSCiLS登録名あり | 登録名を自動使用 |
| 登録名なし、追加DB照合ON | DB候補名 |
| 登録名なし、追加DB照合OFF | m/z |
| 同じ特徴量の名前が入力間で競合 | その特徴量をm/z表示。候補・出典を保持 |

「分子情報の追加」でDB照合を明示的にONにした場合だけ追加照合を行います。以前のCSVパスが残っていても、OFFでは追加照合しません。再解析でもON/OFFを保存・復元します。

イオンモードはDB照合またはキャリブレーション使用時に指定します。DB照合の許容誤差と入力間のm/zアライメント許容誤差は別の設定です。名称の変更だけで異なるm/zや付加イオンの特徴量を統合することはありません。

## 再解析・中断・旧結果

- 通常解析では、PCAごとにUMAP・クラスタ・対応するマーカー結果を作成します。
- reductionのみの実行では、下流処理は未完了です。「続きを実行」で保存した条件を継承して完成させます。
- クラスタ抽出／除外後の再解析は、選択後の画素でPCAを再計算します。
- Harmony／RPCAが失敗しても、それ以前に保存できたPCAは利用できます。各手法の「完了・条件不足で未実行・失敗」を確認してください。PCAを失敗した手法の代用品として表示しません。
- OSやプロセスの強制終了前に保存が完了した結果は残ります。書き込み自体が完了していない結果まで復旧できるとは限りません。
- 旧結果からHarmonyを基に派生表示するPCAは、未補正PCA由来のUMAPに既存Harmonyのクラスタ定義を載せる場合があります。画面の注記を確認してください。新規解析の独立したPCAと同じクラスタ比較としては扱えません。

既存の表示名やH&E重ね合わせの対応キーは維持します。切片の統合単位やPCAクラスタを再計算した場合は、座標・クラスタ・マーカー結果が変わり得ます。
