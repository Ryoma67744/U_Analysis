# MSI Analysis Application - Claude Code 絶対厳守ルール

## 1. 実装前の確認（最優先）
- コード変更を行う前に、必ず変更内容を提示して「これでいいか？」の確認を取る
- ユーザーの明示的な許可（「実装して」「OK」等）を得てから実装を開始する
- 大規模変更はプランモードで設計を先に提示する

## 2. 変更範囲の厳守
- 指定された機能改修・修正に関連するスクリプト以外は一切変更しない
- 関連スクリプトであっても、指示されていない変更を行う場合は必ず許可を得る
- 既存コードのリファクタリング、フォーマット変更、コメント追加は指示がない限り禁止

## 3. Git コミットルール
- コミットメッセージは日本語で、1行目に日付と時刻を入れる
  - 例: `2026-02-15 14:30 サブプロジェクト設定保存機能を追加`
- 登録前に変更内容を提示し、許可を取ってから実行する
- ユーザーが明示的に「登録して」と言うまでコミットしない
- 時刻の訂正指示はコミット実行の許可ではない

## 4. 回答形式
- 回答の最後の1文には必ず「回答終了」と表示する
- スクリプトを変更した後には「スクリプト反映終了」と表示する
- 日本語で回答する
