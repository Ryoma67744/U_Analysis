第1章 はじめに

1.1 アプリの概要

MSI Analysis Application は、質量分析イメージング（Mass Spectrometry Imaging, MSI）データの UMAP解析・クラスタリング・可視化を行うためのWebアプリケーションです。 ブラウザ上で動作し、以下の機能を提供します。

  • UMAP解析の実行 — Rスクリプトを自動実行し、次元削減・クラスタリングを行います
  • インタラクティブ可視化 — UMAP、Spatial Mapping、Feature Plot、Volcano Plot、Heatmap をブラウザ上で操作できます
  • レポート出力 — 解析結果を PowerPoint（.pptx）ファイルとして自動生成します
  • プロジェクト管理 — 解析設定をプロジェクト単位で保存・管理できます

1.2 対応装置

装置解析手法スクリプトバージョン
DESI-MSIUMAP Template 解析v13
TIMS-MSIDBSCAN + UMAP 解析ver13

どちらの装置でも、新規解析と再解析（クラスタフィルター）に対応しています。

第2章 環境構築

2.1 必要なソフトウェア

Python のインストール（必須）

Python 3.10 以上が必要です。以下の手順でインストールしてください。

  1. python.org にアクセスし、最新の Python 3.x をダウンロードします
  2. インストーラを実行します
  3. 重要: インストール画面の一番下にある 「Add Python to PATH」にチェックを入れてから「Install Now」をクリックしてください
  4. インストール完了後、コマンドプロンプトを開いて以下を入力し、バージョンが表示されることを確認します
python --version

例: Python 3.12.5 と表示されれば成功です。

「Add Python to PATH」にチェックを入れ忘れた場合、アプリが起動できません。 その場合は Python を一度アンインストールし、再度インストールしてください。

R のインストール（推奨）

R は UMAP解析・クラスタリングの実行に必要です。インタラクティブ解析のみ使用する場合は不要です。

  1. OS に合わせて R 4.4.x をダウンロードします:
    • Windows: CRAN (Windows)
    • macOS: CRAN (macOS)
    • Linux (Ubuntu/Debian): sudo apt install r-base r-base-dev
  2. インストーラを実行し、デフォルト設定のまま進めます
  3. Windows ではインストール先 C:\Program Files\R\R-4.4.x を推奨します
R のインストール先を変更した場合、または Mac/Linux で which R が標準と異なる場合は、 App/app/config.py 内の R_HOME を修正してください。 Mac の Homebrew 版 R や Linux の /usr/lib/R は setup.sh が自動検出します。

2.2 アプリのセットアップ

フォルダの配置

アプリ一式が入ったフォルダ（UMAP-WebApp-ClaudeCode）を任意の場所にコピーします。

セットアップの実行（Windows）

  1. エクスプローラーで UMAP-WebApp-ClaudeCode/ フォルダを開きます
  2. setup.bat をダブルクリックします
  3. コマンドプロンプトが開き、以下の処理が自動実行されます:
    • Python のバージョン確認
    • 必要な Python パッケージのインストール
    • R の確認（インストールされている場合のみ）
    • R パッケージのインストール（初回は10〜20分かかります）
  4. 「セットアップが完了しました」と表示されたら完了です。何かキーを押してウィンドウを閉じます

セットアップの実行（macOS / Linux）

  1. ターミナルを開き、UMAP-WebApp-ClaudeCode/ へ移動します: 
    cd ~/path/to/UMAP-WebApp-ClaudeCode
  2. セットアップスクリプトに実行権限を付与し、実行します: 
    chmod +x setup.sh run_app.sh
./setup.sh
  3. 処理内容は Windows と同じです（Python・R パッケージのインストール）
macOS で Gatekeeper 警告が出る場合:

スクリプトは壊れていません。 未署名のシェルスクリプトに対する macOS 標準のセキュリティロックです。 ダウンロードや iCloud Drive / AirDrop 経由で配置した setup.sh / run_app.sh には com.apple.quarantine 属性が付与され、ダブルクリック起動がブロックされます。

macOS Sequoia (15.x) 以降では以下のダイアログが表示されます:

"run_app.sh" は開いていません
Apple は、"run_app.sh" に Mac に損害を与えたり、プライバシーを侵害する
可能性のあるマルウェアが含まれていないことを検証できませんでした。
[ゴミ箱に入れる] [完了]

（macOS Sonoma 以前は「開発元が未確認」「キャンセル / 開く」の旧ダイアログ）

いずれも初回のみ以下のいずれかで解除すれば、以降は通常どおり起動できます:

  1. 推奨: ターミナルから直接起動 
    cd ~/path/to/UMAP-WebApp-ClaudeCode
./run_app.sh
    ターミナル経由の実行は Gatekeeper の対象外です。
  2. システム設定から許可: 警告が表示された直後に「システム設定」→「プライバシーとセキュリティ」を開き、画面下部の「このまま開く」ボタンを押します。 Touch ID / パスワードで認証するとそのファイルはホワイトリストに登録され、以降ダブルクリックでも起動できます。
  3. quarantine 属性を一括解除: 
    xattr -dr com.apple.quarantine ~/path/to/UMAP-WebApp-ClaudeCode
    フォルダ内の全ファイルから隔離属性を取り除きます。
セットアップは初回のみ実行すれば十分です。 Python や R のバージョンを変更した場合は再度 setup.bat / setup.sh を実行してください。

外部データフォルダの設定（推奨・任意）

重い生データをリポジトリ外の固定パスに置いておけば、アプリを更新（git pull や再 clone）しても 再コピー不要で 過去プロジェクトをそのまま復活できます。

  1. App/.env.example を App/.env にコピーします
  2. .env に以下を追記します（任意・DESI / TIMS それぞれ別パスに設定可）: 
    DESI_DATA_DIR=C:\Users\your-name\MSI_Data\DESI
TIMS_DATA_DIR=C:\Users\your-name\MSI_Data\TIMS
  3. アプリ起動後、サイドバー「プロジェクト復元」からスキャンすると、 旧マシン由来の絶対パスが自動補正され過去プロジェクトが復活します（詳細は第8章）。

未設定時は従来通り同梱の Data/DESI/Data/ / Data/TIMS/Data/ を参照します。

2.3 アプリの起動と終了

起動（Windows）

  1. UMAP-WebApp-ClaudeCode/ フォルダ内の run_app.bat をダブルクリックします
  2. コマンドプロンプトが開き、Starting MSI Analysis Application on http://127.0.0.1:3838 と表示されます
  3. Webブラウザ（Google Chrome 推奨）を開き、アドレスバーに以下を入力します: 
    http://localhost:3838
  4. アプリのトップ画面（プロジェクト一覧）が表示されれば起動完了です

起動（macOS / Linux）

  1. ターミナルで UMAP-WebApp-ClaudeCode/ に移動します
  2. 起動スクリプトを実行します: 
    ./run_app.sh
  3. 同様に http://localhost:3838 をブラウザで開きます

図: アプリ起動後のプロジェクト一覧画面

同じネットワーク上の別PCからアクセスする場合は、http://[このPCのIPアドレス]:3838 で接続できます。 外部ネットワークから共有する場合は、第10章「共有リンク」と App/docs/DEPLOY.md を参照してください。

終了

アプリを終了するには、起動した run_app.bat または run_app.sh のターミナル/コマンドプロンプトウィンドウを閉じてください （または Ctrl+C で停止してから閉じます）。 ブラウザのタブを閉じるだけではアプリは終了しません。

4.1 TIMS解析

データの準備

TIMS装置で取得したデータファイル（.parquet、.csv、.txt 等）を 1つのフォルダにまとめておきます。1ファイル＝1サンプルとして認識されます。

データフォルダの優先ルール:
  • 同じフォルダ内に .parquet / .pq が 1 本でもあれば、Parquet のみ がサンプル候補として表示されます （複数 Parquet は並列解析可）。共存する .csv / .tsv / .txt は自動的に非表示になります。
  • Parquet が 1 本も無い場合のみ、.csv / .tsv / .txt がすべてサンプル候補として表示されます。
  • この仕様により、SCiLS 変換の「サブフォルダ整理 OFF」で生成された中間ファイル （*_Intensity.csv、*_Spot.csv、*_Annotation.csv）は、最終の .parquet が同居していれば自動で隠れます。

SCiLS Lab 出力からの変換（ショートカット）

SCiLS Lab で Export → Feature list (CSV) した出力フォルダは、 サイドバーの 「🔄 SCiLS 変換」 ボタンから .parquet に一括変換できます。

  1. サイドバー下部の 「🔄 SCiLS 変換」 をクリック
  2. 「入力フォルダ」に SCiLS の出力先（例: 260402_SCiLS_Annotation）を指定
  3. 「出力先フォルダ」は既定で TIMS_DATA_DIR。必要なら変更
  4. 「サンプル名」を入力（空欄なら入力フォルダ名を自動採用）
  5. 「変換実行」 をクリックすると <サンプル名>.parquet が生成されます

Long 形式 (id/x/y/mz/intensity) / Wide 形式（m/z 値を列名に持つ形式）を 自動判定し、列名のエイリアス（Spot Index → id、m/z → mz、 Region → annotation 等）も吸収します。 変換後そのまま TIMS 解析のデータフォルダとして指定できます。

解析設定の手順

  1. サイドバーの 「TIMS」 セクションから 「UMAP解析」 を選択します
  2. データフォルダ: 「...」ボタンをクリックし、データが格納されているフォルダを選択します
  3. サンプル選択: 表示されたファイル一覧から、解析対象のサンプルにチェックを入れます
  4. アノテーションファイル（任意）: 代謝物データベースの CSV ファイルを指定します
  5. 出力先フォルダ: 結果の保存先を指定します
  6. 解析名: 自動生成されますが、任意の名前に変更できます

図: TIMS 解析設定画面。左のサイドバーで解析手法を選択し、右側で各種パラメータを設定します

イオンモード設定

m/z キャリブレーション（任意）

マトリックスのリファレンスピークを用いて m/z 値を補正できます。

  1. 「m/z キャリブレーション」 セクションを展開します
  2. マトリックス を選択します（DHB / CHCA / 9-AA / カスタム）
  3. リファレンス m/z 値のテーブルが表示されます。必要に応じて編集します
  4. 「ピーク自動検出」 ボタンで、データ内のピークを自動マッチングできます
  5. 回帰モデル（線形 / 2次 / 3次多項式）を選択します

解析の実行

  1. 設定が完了したら 「解析実行」 ボタンをクリックします
  2. R スクリプトが自動的に実行されます。進捗はプログレスバーとログで確認できます
  3. 解析完了後、結果フォルダに RDS ファイルや画像が生成されます

4.2 DESI解析

データの準備

DESI装置で取得したテキストデータファイル（.txt）を1つのフォルダにまとめておきます。

解析設定の手順

  1. サイドバーの 「DESI」 セクションから 「UMAP解析」 を選択します
  2. データフォルダ: 「...」ボタンでデータフォルダを選択します
  3. サンプル選択: 解析対象のサンプルにチェックを入れます
  4. MRMファイル（任意）: MRM リスト（.xlsx）を指定するとターゲット代謝物が表示されます
  5. 出力先フォルダと解析名を確認します
  6. 「解析実行」 ボタンをクリックします

4.3 再解析（クラスタフィルター）

既に実行済みの解析結果から、特定のクラスタを除外・抽出して再度 UMAP 計算を行えます。

  1. サイドバーで 「再解析」 を選択します
  2. RDSファイル: 「...」ボタンで既存の RDS ファイル（Step2 または Step3）を選択します
  3. 対象クラスタ: クラスタ番号をカンマ区切りで入力します（例: 0, 1, 5）
  4. フィルターモード: 「除外」（指定クラスタを取り除く）または「抽出」（指定クラスタのみ残す）を選択します
  5. 「解析実行」 ボタンをクリックします

4.4 解析の進捗確認

解析実行中は以下の情報が表示されます:

  • プログレスバー: 全体の進捗を表示
  • ステータスメッセージ: 現在実行中の処理内容
  • ログ出力: R スクリプトの実行ログがリアルタイムで表示されます
解析にかかる時間はデータサイズとサンプル数によって異なります。 目安として、5サンプル・各1000ピクセル程度で 5〜15分 程度です。

第6章 インタラクティブ解析

本アプリの中心機能です。解析結果をブラウザ上でリアルタイムに操作し、 クラスタの特徴や代謝物の空間分布を詳細に調べることができます。

各セクション（UMAP、Spatial Mapping 等）はタイトルをクリックすると折りたたみ/展開できます。 「インタラクティブ解析」セクション全体も折りたたみ可能です。

6.1 データの読み込み

  1. 画面上部の 「インタラクティブ」 タブをクリックします
  2. 設定タブで解析を実行した場合、結果は自動的に読み込まれます
  3. 手動で読み込む場合は、結果フォルダのドロップダウンまたは「...」ボタンから 結果フォルダを選択します
  4. 解析時には Harmony/PCA と RPCA の 2 手法が自動で並列実行されます。 結果フォルダに両方の RDS が存在する場合、インタラクティブタブ上部の 解析手法セレクター（ドロップダウン）で「Harmony/PCA」「RPCA」を切り替えながら 同一データを別視点で比較できます

図: インタラクティブタブ。結果フォルダを指定してデータを読み込んだ状態。読み込み完了メッセージにセル数・クラスタ数・サンプル情報が表示されます

データの読み込みには RDS ファイルから Python 形式への変換が行われるため、 初回は数十秒〜数分かかる場合があります。2回目以降はキャッシュにより高速になります。

6.7 m/z キャリブレーション

インタラクティブ解析画面で、マトリックスのリファレンスピークを用いた m/z キャリブレーション（補正）を行えます。 解析設定タブのキャリブレーション機能と同様のロジックで、読み込み済みデータに対してリアルタイムに補正を適用できます。

設定手順

  1. 「▶ イオンモード / m/z キャリブレーション」 セクションを展開します
  2. イオンモードを選択します（Positive / Negative）
  3. 付加イオンを選択します（Positive: +H, +Na, +NH4 / Negative: -H）
    — イオンモードを切り替えると自動的に適切な付加イオンが選択されます
  4. マトリックスを選択します（DHB / CHCA / 9-AA / カスタム）
  5. リファレンス m/z テーブルが表示されます。「ピーク自動検出」ボタンで データ内のピークと自動マッチングし、観測 m/z 値が入力されます
  6. 回帰モデル（線形 / 2次 / 3次多項式）を選択します
  7. 「補正を適用」 ボタンをクリックすると、m/z 値が補正されます

設定項目

項目説明デフォルト
イオンモードPositive / Negative の切り替えPositive
付加イオン対象とするアダクトイオン種+H, +Na, +NH4（Positive時）
マトリックスリファレンスピークの元になるマトリックス種DHB
MRMファイルMRM リスト（DESI解析の場合のみ表示）―
検索ウィンドウピーク自動検出の検索幅（Da）0.5
最小ピーク数回帰に使用する最小ピーク数2
回帰モデルlinear / poly2 / poly3poly3
キャリブレーション設定は結果フォルダごとに自動保存されます。 次回同じデータを読み込んだ際に、前回の設定（観測 m/z 値を含む）が自動的に復元されます。

6.7.1 サンプル別キャリブレーション

複数サンプルが混在するデータでは、サンプルごとに異なる m/z オフセットが生じる場合があります。 本アプリでは、全サンプル共通のキャリブレーションに加え、 サンプル単位での個別補正にも対応しています。

サンプル別設定の有効化

  1. キャリブレーションセクションの 「サンプル別設定」 チェックボックスを ON にします
  2. サンプルドロップダウンが表示されるので、補正を行いたいサンプルを選択します
  3. 選択中のサンプルに対して、リファレンス m/z テーブルで観測値を個別に入力 / ピーク自動検出を実行します
  4. 「補正を適用」 をクリックすると、選択中のサンプルのみに補正が反映されます
  5. 他のサンプルに切り替えて、同様の手順で個別補正を設定します

共通設定との使い分け

モード用途
共通設定（デフォルト）全サンプル同一ロットのマトリックスで測定され、共通の m/z ずれを補正する場合
サンプル別設定サンプルごとに測定日・マトリックスロットが異なり、個別補正が必要な場合
サンプル別キャリブレーションの設定も、結果フォルダごとに保存されます。 サンプル名・観測 m/z 値・回帰係数が Data/Other/sessions/ 以下に記録されます。
まず「共通設定」で全体を補正し、それでも残存する誤差が大きいサンプルに対してのみ 「サンプル別設定」を使うのが効率的です。

プロジェクト復元（外部生データからの自動復活）

アプリを別マシンで再 clone したり git pull で更新した場合、projects.json に 保存された絶対パスは旧マシン由来で壊れています。本機能は、 現在の DESI_DATA_DIR / TIMS_DATA_DIR 配下を再帰スキャンし、 末尾フォルダ名が一致するデータを見つけて パスを自動補正します。

  1. 事前に App/.env で DESI_DATA_DIR / TIMS_DATA_DIR を設定 （第2.2章「外部データフォルダの設定」参照）
  2. サイドバーの 「🔄 プロジェクト復元」 ボタンをクリック
  3. 外部 DATA_ROOT 配下に残っている _project_meta.json が検出され、 破損パスが自動補正された状態で一覧表示されます
  4. 「復元」ボタンで projects.json に登録されます

補正に失敗したパス（同名フォルダが見つからない場合）は警告として列挙されるので、 必要に応じてファイルブラウザから手動指定してください。

旧パス（Data/DESI/Data/ 等）も探索対象（legacy fallback）に含まれるため、 .env を設定していない既存ユーザでも問題なく復元できます。

第10章 共有リンク

解析結果のインタラクティブビューを URL で他のユーザと共有できます。 共有先のユーザは 閲覧専用モード でアクセスでき、データの書き換えはできません。

10.1 共有 URL の発行

  1. トップページ（プロジェクト一覧）で共有したいサブプロジェクトを選択します
  2. サブプロジェクトカードの 「共有」 ボタンをクリックします
  3. 共有作成モーダルが開きます。以下の項目を設定します:
    項目説明
    有効期限発行から何日間有効とするか（例: 7 日、30 日）。空欄で無期限
    解析手法共有する結果を「Harmony/PCA」または「RPCA」から選択
    メモ共有先に伝える任意メモ（例: 「3/15 ミーティング用」）
  4. 「リンク生成」 をクリックすると共有 URL が表示されます
  5. URL をコピーして共有先に送付します
共有 URL にアクセスできるユーザは、結果データを閲覧できます。 外部公開前に、機密データが含まれていないか必ず確認してください。

10.2 共有ページへのアクセス

共有 URL をブラウザで開くと、読み取り専用のインタラクティブビューが表示されます。 共有先ユーザが利用できる機能は以下のとおりです:

  • Spatial Mapping（サンプルフィルター、ハイライト）
  • Feature Plot（遺伝子 / m/z ごとの発現強度可視化）

  • DEG マーカーテーブル
  • 結果ギャラリー（出力画像ブラウジング）

サーバー設定

10.3 有効期限と削除

共有リンク一覧の確認

  1. トップページで対象プロジェクトを開き、サブプロジェクト一覧の下部にある 「共有リンク一覧」 セクションを確認します
  2. プロジェクト内の全共有リンクが、有効期限・作成日・メモ付きで表示されます
  3. 期限切れのリンクには 「期限切れ」 バッジが表示されます

共有リンクの削除

  1. 一覧から削除したいリンクの 「🗑 削除」 ボタンをクリックします
  2. 確認モーダルで 「削除」 を押すと、即座に URL が無効化されます
共有データは Data/Other/shares/shares.json に記録されます。 期限切れのリンクは、新規リンク発行時に自動クリーンアップされます。 手動で削除する場合は、上記の「共有リンクの削除」手順を利用してください。
