MSI Analysis Application - セットアップガイド

別の PC でアプリケーションを実行するための環境構築手順です。

必要なもの

ソフトウェアバージョン必須?用途
Python3.10 以上必須Web アプリケーション本体
R4.4 以上解析を行う場合のみUMAP 解析・クラスタリング・DEG 検出
R が不要なケース: 他の PC で解析済みの RDS ファイルを持ち込んで、 インタラクティブ可視化（UMAP・Spatial Mapping・Feature Plot 等）のみ利用する場合は R は不要です。

Step 1: ZIP ファイルの展開

1 MSI_Analysis_App_v2.1.0.zip を任意のフォルダに展開（解凍）します。

注意: パスに日本語（全角文字）が含まれるフォルダは避けてください。 例: C:\MSI_App\ のような英数字のみのパスを推奨します。 デスクトップ（C:\Users\ユーザー名\Desktop）は日本語ユーザー名の場合に問題が起きることがあります。

Step 2: Python のインストール

2 Python がまだインストールされていない場合は、以下からダウンロードしてインストールします。

ダウンロード: https://www.python.org/downloads/

重要: インストール時に 「Add Python to PATH」 に必ずチェックを入れてください。 これを忘れると、コマンドプロンプトから Python を実行できません。

インストール後、コマンドプロンプトで確認:

python --version
# 出力例: Python 3.12.2

Step 3: R のインストール（任意）

3 UMAP 解析・クラスタリングを実行する場合は R もインストールします。

ダウンロード: https://cran.r-project.org/bin/windows/base/

インストール先はデフォルト (C:\Program Files\R\R-4.x.x) を推奨します。

R のインストールパスがデフォルトと異なる場合は、展開したフォルダ内の .env.example を .env にコピーし、 R_HOME の値を実際のパスに書き換えてください。

Step 4: セットアップの実行

4 展開したフォルダ内の setup.bat をダブルクリックします。

自動で以下が実行されます:

  1. Python の存在チェック
  2. Python パッケージのインストール（Dash, Plotly, pandas 等）
  3. R の存在チェック（見つからない場合はスキップ）
  4. R パッケージのインストール（Seurat, harmony 等 — 初回は10〜20分かかります）
Python パッケージのインストールにはインターネット接続が必要です。 初回は 2〜5 分程度かかります。

Step 5: アプリの起動

5 フォルダ内の run_app.bat をダブルクリックします。

コマンドプロンプトに以下のようなメッセージが表示されたら起動完了です:

Dash is running on http://127.0.0.1:3838/

ブラウザが自動で開きます。開かない場合は、ブラウザで http://127.0.0.1:3838/ にアクセスしてください。

起動成功! ブラウザにアプリの画面が表示されれば、セットアップは完了です。

データの配置

解析データは以下のフォルダに配置します:

データ種別配置先
TIMS-MSI データdata/TIMS/Data/
DESI-MSI データdata/DESI/Data/

アプリ内のファイルブラウザから任意のフォルダを指定することも可能です。

トラブルシューティング

「Python が見つかりません」と表示される

  • Python のインストール時に「Add Python to PATH」にチェックを入れたか確認してください
  • コマンドプロンプトを一度閉じて開き直してください（PATH の反映に再起動が必要な場合があります）

「pip install に失敗した」と表示される

  • インターネット接続を確認してください
  • プロキシ環境の場合は、IT 部門に pip の設定方法を確認してください

ブラウザに画面が表示されない

  • コマンドプロンプトにエラーメッセージが出ていないか確認してください
  • ポート 3838 が他のアプリで使用されている可能性があります。.env ファイルで APP_PORT を変更できます

R の解析が実行できない

  • R が正しくインストールされているか確認: コマンドプロンプトで Rscript --version
  • .env の R_HOME が実際のインストールパスと一致しているか確認
  • setup.bat を再実行して R パッケージをインストールしてください

  pyproject.toml       ... パッケージ定義
  requirements.txt     ... Python 依存パッケージ
  .env.example         ... 環境設定テンプレート
  install_r_packages.R ... R パッケージインストーラ
  app/                 ... アプリケーション本体
  data/
    TIMS/
      Script/          ... TIMS 解析用 R スクリプト
      DB/              ... アノテーション DB
      Data/            ... (ここにデータを配置)
    DESI/
      Script/          ... DESI 解析用 R スクリプト
      DB/              ... アノテーション DB
      Data/            ... (ここにデータを配置)
    Common/
      Script/          ... 共通 R スクリプト
  docs/                ... ドキュメント
  tests/               ... テストコード
