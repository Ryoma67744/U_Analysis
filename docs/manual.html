第1章 はじめに

1.1 アプリの概要

MSI Analysis Application は、質量分析イメージング（Mass Spectrometry Imaging, MSI）データの UMAP解析・クラスタリング・可視化を行うためのWebアプリケーションです。 ブラウザ上で動作し、以下の機能を提供します。

  • UMAP解析の実行 — Rスクリプトを自動実行し、次元削減・クラスタリングを行います
  • インタラクティブ可視化 — UMAP、Spatial Mapping、Feature Plot、Volcano Plot、Heatmap をブラウザ上で操作できます
  • レポート出力 — 解析結果を PowerPoint（.pptx）ファイルとして自動生成します
  • プロジェクト管理 — 解析設定をプロジェクト単位で保存・管理できます

1.2 対応装置

装置解析手法スクリプトバージョン
DESI-MSIUMAP Template 解析v9
TIMS-MSIDBSCAN + UMAP 解析ver13

どちらの装置でも、新規解析と再解析（クラスタフィルター）に対応しています。

第2章 環境構築

2.1 必要なソフトウェア

Python のインストール（必須）

Python 3.10 以上が必要です。以下の手順でインストールしてください。

  1. python.org にアクセスし、最新の Python 3.x をダウンロードします
  2. インストーラを実行します
  3. 重要: インストール画面の一番下にある 「Add Python to PATH」にチェックを入れてから「Install Now」をクリックしてください
  4. インストール完了後、コマンドプロンプトを開いて以下を入力し、バージョンが表示されることを確認します
python --version

例: Python 3.12.5 と表示されれば成功です。

「Add Python to PATH」にチェックを入れ忘れた場合、アプリが起動できません。 その場合は Python を一度アンインストールし、再度インストールしてください。

R のインストール（推奨）

R は UMAP解析・クラスタリングの実行に必要です。インタラクティブ解析のみ使用する場合は不要です。

  1. CRAN から R 4.4.x をダウンロードします
  2. インストーラを実行し、デフォルト設定のまま進めます
  3. インストール先はデフォルトの C:\Program Files\R\R-4.4.x を推奨します
R のインストール先を変更した場合は、アプリの設定ファイル（app/config.py）内の R_HOME を修正する必要があります。

2.2 アプリのセットアップ

フォルダの配置

アプリ一式が入ったフォルダ（UMAP_Claudecode）を任意の場所にコピーします。

セットアップの実行

  1. エクスプローラーで UMAP_Claudecode フォルダを開きます
  2. setup.bat をダブルクリックします
  3. コマンドプロンプトが開き、以下の処理が自動実行されます:
    • Python のバージョン確認
    • 必要な Python パッケージのインストール
    • R の確認（インストールされている場合のみ）
    • R パッケージのインストール（初回は10〜20分かかります）
  4. 「セットアップが完了しました」と表示されたら完了です。何かキーを押してウィンドウを閉じます
セットアップは初回のみ実行すれば十分です。 Python や R のバージョンを変更した場合は再度 setup.bat を実行してください。

2.3 アプリの起動と終了

起動

  1. UMAP_Claudecode フォルダ内の run_app.bat をダブルクリックします
  2. コマンドプロンプトが開き、Starting MSI Analysis Application on http://127.0.0.1:3838 と表示されます
  3. Webブラウザ（Google Chrome 推奨）を開き、アドレスバーに以下を入力します: 
    http://localhost:3838
  4. アプリのトップ画面（プロジェクト一覧）が表示されれば起動完了です

図: アプリ起動後のプロジェクト一覧画面

同じネットワーク上の別PCからアクセスする場合は、http://[このPCのIPアドレス]:3838 で接続できます。

終了

アプリを終了するには、run_app.bat のコマンドプロンプトウィンドウを閉じてください。 ブラウザのタブを閉じるだけではアプリは終了しません。

第3章 プロジェクト管理

アプリを起動すると、まずプロジェクト一覧画面（ランディングページ）が表示されます。 解析データをプロジェクト単位で整理・管理できます。

3.1 プロジェクトの作成

  1. 画面左上の 「+ 新規プロジェクト」 ボタンをクリックします
  2. プロジェクト名を入力します（例: 240301-田中-肝臓）
  3. 必要に応じて説明を入力します
  4. 「作成」 ボタンをクリックします

図: プロジェクト一覧画面。右上の「+ 新規プロジェクト」から作成できます

3.2 サブプロジェクトの作成

プロジェクトをクリックすると、サブプロジェクト一覧画面に移動します。 1つのプロジェクト内に複数のサブプロジェクト（解析条件の異なる実験など）を作成できます。

  1. プロジェクト一覧から対象のプロジェクトをクリックします
  2. 「+ 新規サブプロジェクト」 ボタンをクリックします
  3. サブプロジェクト名を入力し、解析対象の装置（DESI / TIMS）を選択します
  4. 「作成」 ボタンをクリックします

図: サブプロジェクト一覧画面。「解析」「結果閲覧」「インタラクティブ」から各機能にアクセスできます

3.3 プロジェクトの検索・編集・削除

  • 検索: プロジェクト一覧画面上部の検索バーにキーワードを入力すると、プロジェクトが絞り込まれます
  • 編集: プロジェクト名の右側にある編集アイコンをクリックして名前や説明を変更できます
  • 削除: 削除アイコンをクリックすると確認ダイアログが表示されます。削除は取り消せません

第4章 解析の実行（設定タブ）

サブプロジェクトを選択し 「解析開始」 をクリックすると、設定画面に移動します。 左側のサイドバーで解析手法を選び、各種パラメータを設定して解析を実行します。

4.1 TIMS解析

データの準備

TIMS装置で取得したデータファイル（.parquet、.csv、.txt 等）を 1つのフォルダにまとめておきます。1ファイル＝1サンプルとして認識されます。

解析設定の手順

  1. サイドバーの 「TIMS」 セクションから 「UMAP解析」 を選択します
  2. データフォルダ: 「...」ボタンをクリックし、データが格納されているフォルダを選択します
  3. サンプル選択: 表示されたファイル一覧から、解析対象のサンプルにチェックを入れます
  4. アノテーションファイル（任意）: 代謝物データベースの CSV ファイルを指定します
  5. 出力先フォルダ: 結果の保存先を指定します
  6. 解析名: 自動生成されますが、任意の名前に変更できます

図: TIMS 解析設定画面。左のサイドバーで解析手法を選択し、右側で各種パラメータを設定します

イオンモード設定

設定項目説明デフォルト値
イオンモードPositive（陽イオン）または Negative（陰イオン）Positive
m/z トレランスm/z 値のマッチング許容差（Da）0.01
アダクトフィルタ対象とするアダクトイオン種+H, +Na, +NH4（Positive時）

m/z キャリブレーション（任意）

マトリックスのリファレンスピークを用いて m/z 値を補正できます。

  1. 「m/z キャリブレーション」 セクションを展開します
  2. マトリックス を選択します（DHB / CHCA / 9-AA / カスタム）
  3. リファレンス m/z 値のテーブルが表示されます。必要に応じて編集します
  4. 「ピーク自動検出」 ボタンで、データ内のピークを自動マッチングできます
  5. 回帰モデル（線形 / 2次 / 3次多項式）を選択します

図: 設定画面下部。出力設定と「解析実行」ボタンが表示されます

解析パラメータ

パラメータ説明デフォルト値
p値閾値DEG（差次的発現）の有意水準0.05
log2FC 閾値発現変動量の最小値0.1

解析の実行

  1. 設定が完了したら 「解析実行」 ボタンをクリックします
  2. R スクリプトが自動的に実行されます。進捗はプログレスバーとログで確認できます
  3. 解析完了後、結果フォルダに RDS ファイルや画像が生成されます

4.2 DESI解析

データの準備

DESI装置で取得したテキストデータファイル（.txt）を1つのフォルダにまとめておきます。

解析設定の手順

  1. サイドバーの 「DESI」 セクションから 「UMAP解析」 を選択します
  2. データフォルダ: 「...」ボタンでデータフォルダを選択します
  3. サンプル選択: 解析対象のサンプルにチェックを入れます
  4. MRMファイル（任意）: MRM リスト（.xlsx）を指定するとターゲット代謝物が表示されます
  5. 出力先フォルダと解析名を確認します
  6. 「解析実行」 ボタンをクリックします

4.3 再解析（クラスタフィルター）

既に実行済みの解析結果から、特定のクラスタを除外・抽出して再度 UMAP 計算を行えます。

  1. サイドバーで 「再解析」 を選択します
  2. RDSファイル: 「...」ボタンで既存の RDS ファイル（Step2 または Step3）を選択します
  3. 対象クラスタ: クラスタ番号をカンマ区切りで入力します（例: 0, 1, 5）
  4. フィルターモード: 「除外」（指定クラスタを取り除く）または「抽出」（指定クラスタのみ残す）を選択します
  5. 「解析実行」 ボタンをクリックします

4.4 解析の進捗確認

解析実行中は以下の情報が表示されます:

  • プログレスバー: 全体の進捗を表示
  • ステータスメッセージ: 現在実行中の処理内容
  • ログ出力: R スクリプトの実行ログがリアルタイムで表示されます
解析にかかる時間はデータサイズとサンプル数によって異なります。 目安として、5サンプル・各1000ピクセル程度で 5〜15分 程度です。

  3. フォルダ内のサブフォルダが一覧表示されます

図: 結果閲覧タブ。結果フォルダを選択し、カテゴリ・クラスタでフィルタリングできます

5.2 カテゴリ・クラスタフィルター

結果画像を種類やクラスタで絞り込めます。

第6章 インタラクティブ解析

本アプリの中心機能です。解析結果をブラウザ上でリアルタイムに操作し、 クラスタの特徴や代謝物の空間分布を詳細に調べることができます。

各セクション（UMAP、Spatial Mapping 等）はタイトルをクリックすると折りたたみ/展開できます。 「インタラクティブ解析」セクション全体も折りたたみ可能です。

6.1 データの読み込み

  1. 画面上部の 「インタラクティブ」 タブをクリックします
  2. 設定タブで解析を実行した場合、結果は自動的に読み込まれます
  3. 手動で読み込む場合は、結果フォルダのドロップダウンまたは「...」ボタンから 結果フォルダを選択します
  4. 複数の解析手法（Harmony / RPCA など）がある場合、 解析手法セレクターで切り替えられます

図: インタラクティブタブ。結果フォルダを指定してデータを読み込んだ状態。読み込み完了メッセージにセル数・クラスタ数・サンプル情報が表示されます

データの読み込みには RDS ファイルから Python 形式への変換が行われるため、 初回は数十秒〜数分かかる場合があります。2回目以降はキャッシュにより高速になります。

6.5 DEGマーカー解析

DEGマーカー セクションでは、差次的発現解析の結果を Volcano Plot と Heatmap で可視化します。

Volcano Plot

横軸に log2 Fold Change、縦軸に -log10(p-value) をプロットした散布図です。

  • 赤い点: 発現が上昇した有意なマーカー（Up-regulated）
  • 青い点: 発現が低下した有意なマーカー（Down-regulated）
  • 灰色の点: 有意でないマーカー
調整項目説明デフォルト
FC 閾値Fold Change の閾値（縦の破線位置）0.5
-log10(p) 閾値有意水準の閾値（横の破線位置）1.3
クラスタ選択特定クラスタのマーカーだけを表示全て
ポイントサイズ点の大きさ8

図: DEG マーカーセクション。Volcano Plot タブでは FC 閾値・p 値閾値を調整してマーカーを可視化します

6.6 クラスタ情報

クラスタ情報 セクションでは以下の機能を利用できます。

統計テーブル

各クラスタのピクセル数と全体に占める割合が表で表示されます。

クラスタ色のカスタマイズ

各クラスタに割り当てる色を変更できます。カラーピッカーで任意の色を選択してください。 変更は全てのプロット（UMAP、Spatial Mapping、Feature Plot）に即座に反映されます。

サンプル名の変更

元のファイル名の代わりに、表示用のサンプル名を設定できます。 変更した名前はプロットのタイトルや凡例、レポート出力にも反映されます。

図: クラスタ情報セクション。クラスタ統計テーブル（ピクセル数・割合）が表示されます

6.7 m/z キャリブレーション

インタラクティブ解析画面で、マトリックスのリファレンスピークを用いた m/z キャリブレーション（補正）を行えます。 解析設定タブのキャリブレーション機能と同様のロジックで、読み込み済みデータに対してリアルタイムに補正を適用できます。

設定手順

  1. 「▶ イオンモード / m/z キャリブレーション」 セクションを展開します
  2. イオンモードを選択します（Positive / Negative）
  3. 付加イオンを選択します（Positive: +H, +Na, +NH4 / Negative: -H）
    — イオンモードを切り替えると自動的に適切な付加イオンが選択されます
  4. マトリックスを選択します（DHB / CHCA / 9-AA / カスタム）
  5. リファレンス m/z テーブルが表示されます。「ピーク自動検出」ボタンで データ内のピークと自動マッチングし、観測 m/z 値が入力されます
  6. 回帰モデル（線形 / 2次 / 3次多項式）を選択します
  7. 「補正を適用」 ボタンをクリックすると、m/z 値が補正されます

設定項目

項目説明デフォルト
イオンモードPositive / Negative の切り替えPositive
付加イオン対象とするアダクトイオン種+H, +Na, +NH4（Positive時）
マトリックスリファレンスピークの元になるマトリックス種DHB
MRMファイルMRM リスト（DESI解析の場合のみ表示）―
検索ウィンドウピーク自動検出の検索幅（Da）0.5
最小ピーク数回帰に使用する最小ピーク数2
回帰モデルlinear / poly2 / poly3poly3
キャリブレーション設定は結果フォルダごとに自動保存されます。 次回同じデータを読み込んだ際に、前回の設定（観測 m/z 値を含む）が自動的に復元されます。

第7章 レポート出力

インタラクティブ解析の結果を PowerPoint（.pptx）ファイルとして出力できます。

7.1 PPTXエクスポート

  1. インタラクティブタブの 「エクスポート」 セクションを展開します
  2. Top N: 各クラスタの上位何個のマーカーを含めるかを設定します（デフォルト: 5）
  3. 出力手法: 複数の解析手法がある場合、出力対象を選択します（「All」で全手法を含む）
  4. 「レポート出力 (.pptx)」 ボタンをクリックします
  5. プログレスバーが表示され、生成が完了するとファイルが自動ダウンロードされます

図: エクスポートセクション。Top N と出力対象を設定し「レポート出力 (.pptx)」で PowerPoint を生成します

出力されるスライド構成

1つの解析手法あたり、以下のスライドが生成されます:

スライド内容
1. タイトルプロジェクト情報・日付・サンプル一覧
2. HeatmapTop N DEG の Z-score ヒートマップ
3. UMAP & Spatialサンプル別の UMAP（上段）と Spatial（下段）
4. UMAP (by Sample)全サンプルを色分けした統合 UMAP
5. クラスタ統計各クラスタのピクセル数・割合テーブル
6〜 クラスタ詳細各クラスタの DEG 解析（Volcano + Feature Plot）と UMAP/Spatial ハイライト表示。クラスタ数 × 2 スライド
複数の解析手法を同時に出力する場合、先頭に各手法を比較する概要スライド（UMAP & Spatial / UMAP by Sample）が追加されます。

第8章 セッション管理

解析設定やUIの状態をセッションとして保存し、後から復元できます。

セッションの保存

  1. サイドバーの 「💾 保存」 ボタンをクリックします
  2. 現在の設定（データフォルダ、パラメータ、解析結果パス等）が保存されます

セッションの読み込み

  1. サイドバーの 「📂 読込」 ボタンをクリックします
  2. 保存済みのセッション一覧が表示されます
  3. 復元したいセッションを選択してクリックします
  4. 全ての設定が復元され、すぐに解析を再開できます

図: セッション履歴タブ。保存済みセッションの一覧が表示され、読込・削除が可能です

バックアップ一覧

プロジェクトデータの自動バックアップファイルを確認できます。

  1. サイドバーの 「🗂 バックアップ」 ボタンをクリックします
  2. モーダルウィンドウが開き、バックアップファイルの一覧（ファイル名・サイズ・作成日時）が表示されます
  3. 確認後、「閉じる」 ボタンでモーダルを閉じます
バックアップはプロジェクトの保存・更新時に自動的に作成されます。 バックアップファイルは app/projects/backups/ フォルダに保存されます。
セッションデータはアプリの app/sessions/ フォルダに保存されます。 アプリのフォルダを別のPCにコピーすれば、セッションも引き継がれます。

症状原因対処法
run_app.bat をダブルクリックしてもすぐ閉じる Python が PATH に登録されていない Python を再インストールし「Add Python to PATH」にチェックを入れる
ブラウザで localhost:3838 に接続できない アプリが起動していない / ポートが競合している コマンドプロンプトにエラーが出ていないか確認する。他のアプリがポート3838を使用していないか確認する
解析実行ボタンを押してもエラーになる R がインストールされていない / Rパッケージ不足 R をインストール後、setup.bat を再実行する
RDS ファイルの読み込みが失敗する R のバージョン不一致 / Seurat パッケージ不足 setup.bat を再実行し、R パッケージを再インストールする
インタラクティブ画面が真っ白になる データの読み込みに失敗している ブラウザの開発者ツール（F12）でエラーを確認する。コマンドプロンプトのログも確認する
PPTX の出力に失敗する kaleido パッケージの問題 コマンドプロンプトで pip install --upgrade kaleido を実行する
